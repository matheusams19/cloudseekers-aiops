# CloudSeekers

MVP de AIOps desenvolvido para o Enterprise Challenge FIAP + Locaweb.

## Objetivo

Transformar dados históricos de incidentes em inteligência preditiva para:

- previsão de volume P2/P3 em D+1 e D+7;
- classificação do risco de violação de OLA;
- apoio à priorização operacional.

## Arquitetura

Bronze → ETL → Silver → Machine Learning → Gold → Dashboard

## Tecnologias

- Python
- Pandas
- Scikit-learn
- XGBoost
- Azure Data Lake
- Power BI
- Git/GitHub
